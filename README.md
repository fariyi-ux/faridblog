# Farid Gómez — English Portfolio

This folder is ready for GitHub Pages.

## Publish it

1. Create a new public repository on GitHub.
2. Upload `index.html` and the complete `assets` folder without changing their structure.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. GitHub will display the public URL after the deployment finishes.

The page contains five posts, two local audio files, and one Google Drive video embed.
